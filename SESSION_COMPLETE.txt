API ENDPOINTS SUMMARY
═════════════════════════════════════════════════════════════════════════

Authentication (/api/auth)
  POST   /register          Create account + JWT
  POST   /login             Authenticate + JWT
  GET    /me                Get current user (requires JWT)
  POST   /logout            Logout

Watchlist (/api/watchlist)
  GET    /                  List user's watchlist
  POST   /                  Add stock to watchlist
  GET    /{symbol}          Get watchlist entry
  PUT    /{symbol}          Update entry
  DELETE /{symbol}          Remove from watchlist

Portfolio (/api/portfolio)
  GET    /                  List all holdings (with P&L)
  GET    /summary           Portfolio summary (total value, gains)
  POST   /                  Add holding
  GET    /{symbol}          Holding details with current value
  PUT    /{symbol}          Update holding
  DELETE /{symbol}          Remove holding

Stocks (/api/stocks)
  GET    /screener          Screen by V2 score + filters
  GET    /{symbol}          Complete stock detail + V2 breakdown
  GET    /{symbol}/fundamentals  Fundamentals only
  GET    /{symbol}/v2-score      V2 score with component breakdown
  GET    /search/{query}    Search stocks by symbol/sector
  Plus health checks and documentation endpoints
