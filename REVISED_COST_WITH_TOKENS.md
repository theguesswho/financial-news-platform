## Token Cost Breakdown Details

### What generates the most tokens?

1. **File creation** - Each file requires writing code (output tokens)
2. **Testing verification** - Reading back code to verify (input tokens)
3. **Integration** - Connecting components together (tokens)
4. **Documentation** - README, comments (tokens)

### Optimization to reduce tokens:

- Write code efficiently (no bloat)
- Batch similar components together
- Use consistent patterns (reuse code patterns)
- Skip redundant testing (assume Tailwind works)
